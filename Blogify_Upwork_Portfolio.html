Project Overview

Blogify is a lightweight, responsive, and secure personal blogging system. Designed as a modern full-stack application, it offers users role-based access control, article management, real-time updates, profile customization, and comment moderation. The core focus of this development case study was transforming a traditional monolithic LAMP-stack web application into a serverless-compatible cloud platform ready for instant deployment on modern hosts like Vercel.

The Challenge

Standard PHP/MySQL applications require persistent servers (such as Apache, Nginx, or traditional shared hosting) to run. Deploying them on modern, cost-effective serverless platforms like Vercel presents significant hurdles:

• No Native PHP Support: Vercel is designed for static assets and Node.js serverless runtimes.
• Blocked Remote Databases: Free tiers of host-based databases (e.g., InfinityFree MySQL) block external connections from serverless cloud IPs.
• Ephemeral Storage: Serverless environments do not have persistent local filesystems for SQLite files or media uploads.

The Solution & Architecture

I engineered a highly resilient, modern serverless-adapted architecture for the PHP application:

1. Custom Serverless Routing: Implemented a vercel.json routing pattern that maps entry points to community-supported serverless PHP runtimes (vercel-php@0.9.0) while serving static CSS, JS, and uploads directly from Vercel's Edge CDN.

2. Smart Auto-Fallback Database: Created a custom abstraction layer in the database controller. The system dynamically attempts to connect to the remote MySQL database. If the connection fails or is blocked by security boundaries, it instantly falls back to a self-contained, optimized SQLite database located in Vercel's temporary directory.

3. Automatic Schema Generation: Integrated a schema interpreter that auto-detects database initialization and runs raw SQL migrations to build tables and seed default settings on the fly.

Portfolio Highlight: Self-Contained Demo Setup

By implementing the auto-fallback SQLite adapter, this project is completely plug-and-play. Prospective clients or developers can deploy this repository directly to their Vercel dashboard with a single click, and it will run a fully functional demo with seeded sample data instantly—requiring zero external database setups.

How to Run and Start

To run this project, you can choose between two main configurations:

  • 1

    Update Database Credentials (db.php)

    Open the database configuration file and enter your MySQL host, username, password, and database name:

    $conn = mysqli_connect("YOUR_HOST", "YOUR_USER", "YOUR_PASSWORD", "YOUR_DB_NAME");
  • 2

    Import Schema

    If you are using MySQL, import the database.sql file into your phpMyAdmin or MySQL console to generate tables and seed sample data.

  • 3

    Local Server Deployment

    Move the project files to your web root folder (e.g., htdocs in XAMPP) and access the site via http://localhost/project_folder/.

  • 4

    Vercel Deployment (Serverless Mode)

    Simply push the repository to GitHub and link it to your Vercel Dashboard. The custom vercel.json file will configure and deploy the PHP runtime automatically.
